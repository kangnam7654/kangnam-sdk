# Migrating to llm-router v0.5.0

Single breaking change + several additive features. Migration is small
and mostly mechanical for downstream consumers (kangnam-client,
travel-planner, Lunawave, dear-jeongbin).

## Breaking change

### `LlmResponse` is now `#[non_exhaustive]`

External `LlmResponse { ... }` struct literals stop compiling.
**Important**: Rust's `#[non_exhaustive]` rejects ALL struct-literal
expressions from external crates, **even with `..Default::default()`**
(error E0639). The correct pattern is `Default::default()` + field
mutation:

**Before** (v0.4.x):
```rust
LlmResponse {
    rendered_text: text,
    model: "claude".into(),
    estimated_cost_usd: 0.0,
    input_tokens: None,
    output_tokens: None,
    tool_calls: vec![],
}
```

**After** (v0.5.x — correct external pattern):
```rust
let mut resp = LlmResponse::default();
resp.rendered_text = text;
resp.model = "claude".into();
// estimated_cost_usd, input_tokens, output_tokens, tool_calls already
// have correct default values; only override what differs from default.
resp
```

Or as an expression:
```rust
{
    let mut r = LlmResponse::default();
    r.rendered_text = text;
    r.model = "claude".into();
    r
}
```

> **Why `..Default::default()` doesn't work**: `#[non_exhaustive]` is
> Rust's mechanism for "this struct may grow new fields without notice".
> Struct literal syntax — even with FRU (functional record update) —
> requires the caller to acknowledge all required fields, which the
> attribute prevents. The mutation pattern bypasses this constraint.
>
> Inside the `llm-router` crate itself, `..Default::default()` works
> fine (E0639 only applies to external callers). The `llm-router`
> source uses `..Default::default()` everywhere internally.

Sites affected: typically only mock providers in tests. Production code
that consumes `LlmResponse` (reads fields) is unaffected.

## New features (optional, no migration needed)

### Thinking / reasoning blocks

```rust
let opts = LlmRequestOptions {
    thinking_budget_tokens: Some(8192),  // Anthropic
    reasoning_effort: Some("high".into()),  // OpenAI o-series, Gemini 3.x
    ..Default::default()
};

let mut stream = provider.chat_stream_with_options_dyn(...);
while let Some(event) = stream.next().await {
    match event {
        LlmStreamEvent::Thinking { text } => {
            // render in collapsed UI region (gray, smaller text, etc.)
        }
        LlmStreamEvent::Delta { text } => {
            // render normally
        }
        LlmStreamEvent::End { total } => {
            // total.thinking_text contains full accumulated reasoning
        }
        _ => {}
    }
}
```

### Anthropic prompt caching (claude HTTP only)

```rust
use llm_router::CacheBreakpoint;

let opts = LlmRequestOptions {
    cache_breakpoints: vec![
        CacheBreakpoint::System,             // cache long system prompt
        CacheBreakpoint::MessageIndex(0),    // cache RAG context message
    ],
    ..Default::default()
};
let resp = provider.chat_with_options_dyn(&long_system, &messages, &opts, &json!({})).await?;
println!("Cache hits: {:?}", resp.cache_read_input_tokens);
```

Anthropic limits: max 4 cache_breakpoints (excess truncated with warn).
Out-of-range MessageIndex silently skipped with warn.

### Streaming usage events

```rust
while let Some(event) = stream.next().await {
    match event {
        LlmStreamEvent::Usage { output_tokens, estimated_cost_usd, .. } => {
            update_live_cost_display(output_tokens, estimated_cost_usd);
        }
        ...
    }
}
```

Cadence varies per provider:
- **Anthropic**: progressive (every ≥50 output token delta)
- **Gemini**: single event before End (Delta+End wrap)
- **OpenAI / Codex / Copilot**: single event before End (final chunk)
- **Local CLI**: not exposed in v0.5.0
